# 教学论文 v4 复现代码包

这套代码可以完整复现论文（教学范式论文_EN_v4）中的全部数字、表格和图。在自己的电脑上按下面步骤操作即可。

## 一、环境准备

需要 Python 3.9 或更高版本。安装依赖库，在命令行（Windows 按 Win+R 输入 cmd 回车）执行：

```
pip install numpy pandas scipy matplotlib openpyxl
```

├── 任务一_数据准备与时期归属.py
├── 任务二_四诗人风格分析.py
├── 任务三_时期趋势与意象轨迹.py
├── 任务四_共享意象矩阵与自我网络.py
├── 任务五_教材正典证据包.py
├── 任务六_单字共现二元词对比.py       新增：酒／雨／花／月 四诗人对比
├── 任务七_诗人意象共现网络构建.py     新增：四位诗人的真实意象网络（含 Gephi 文件）

## 三、运行方法

在命令行里用 cd 进入 code 目录，然后逐个任务运行：

```
python 任务一_数据准备与时期归属.py
python 任务二_四诗人风格分析.py
python 任务三_时期趋势与意象轨迹.py
python 任务四_共享意象矩阵与自我网络.py
python 任务五_教材正典证据包.py
python 任务六_单字共现二元词对比.py
```

参考耗时：任务一约几秒；任务二约 1 到 2 分钟；任务三约 3 到 5 分钟（要做四次独立训练）；任务四约 2 到 3 分钟；任务五约 1 分钟；任务六约 1 到 2 分钟。

## 四、每个任务对应论文的哪个部分

1. **任务一**：论文 4.2 节的时期归属与各期诗作数（初唐 2,282／盛唐 5,234／中唐 14,015／晚唐 15,117）。
2. **任务二**：表 1（四诗人情感分布与两两检验）、表 2（签名意象）、附录 C（高频意象）、图 1 箱线图、图 2 签名意象条形图、图 3 火山图。
3. **任务三**：图 6 王朝情感曲线（含方差分析 F＝387.64、线性趋势、Tukey 两两比较；配色可在 config.py 的 FIG6_PALETTE 切换，三选一）和意象轨迹两张独立图——图 7 正向（英雄、莲花、花开、杨柳、春色）、图 8 负向（白发、烽火、夕阳、孤舟、伤心、凄凉、憔悴）。
4. **任务四**：表 3 与图 4 共享意象矩阵、图 5 故人自我网络（四位诗人 2×2 对比，config.py 的 EGO_POETS 可减人）。
5. **任务五**：第 7 章教材正典证据包（108 首逐首打分、统计、高频意象）与图 8 哑铃图。
6. **任务六（新增）**：单字共现二元词对比——分别在四位诗人语料中找出与"酒""雨""花""月"在同一首诗中共现的二元词，按 NPMI 排序取前十对比。**共现口径为诗级，与任务四的故人自我网络完全统一**。每个字输出一张四诗人 2×2 对比图（中英双版）加一份完整数据表（共现对比_汇总.csv）和一份速览摘要（共现对比_摘要.txt，内含每位诗人的目标字诗频与占比、前 10 邻居、四诗人 top3 并排对照，写论文直接用）。
7. **任务七（新增）**：诗人意象共现网络构建——为四位诗人各建一张真实网络（节点＝诗人语料中出现不少于 10 次的意象，王维为 5 次；边＝诗级 NPMI≥0.3 且至少共现两首诗；功能词不作节点）。每位诗人输出三个文件（节点.csv、边.csv、网络.gexf），gexf 可直接拖进 Gephi 美化；另附一张 2×2 预览图（中英双版）。阈值在脚本顶部可改。
8. **任务八（新增）**：时期意象共现网络构建——为初唐、盛唐、中唐、晚唐各建一张真实网络，口径与任务七完全一致。每期输出节点表、边表、gexf（可进 Gephi），另附结构指标表（含负向意象占比、枢纽词排名等，写论文用）和 2×2 预览图。
9. **任务九（新增）**：稳健性检验——A 部分用已发布的词典直接做双重证据阈值敏感性（变动阈值，报告通过数与 Jaccard 重叠度）；B 部分在十二组重抽样种子集下重算整条流水线，检验"正典比全集暗""初唐＞盛唐＞中唐""李白居首"三个排序级结论的稳定性。A 几秒，B 约 1 分钟（遍历语料一次）。

## 五、常见调整（只改 config.py 后重跑对应任务）

1. **换轨迹词**：打开 config.py，找到 `TRAJ_POS_WORDS`（图 7 正向）和 `TRAJ_NEG_WORDS`（图 8 负向），删掉不要的词或添加新词（新词记得在 `TRANS` 里补英文译名），然后重跑任务三。
2. **调整非诗意功能词**：打开 config.py，找到 `EXCLUDE`，加词或减词。这个清单同时作用于四个地方：任务二的签名表与高频表、任务四的自我网络邻居、任务五的正典高频意象、任务六的共现对比邻居。剔除后各榜单由后续名次自动递补。改完重跑对应任务即可。
3. **换矩阵的词**：修改 config.py 的 `MATRIX_WORDS`，重跑任务四。
4. **换自我网络的中心词或诗人**：修改 config.py 的 `EGO_TARGET` 和 `EGO_POETS`，重跑任务四。
5. **图中文字体**：代码会依次尝试微软雅黑、黑体、苹方等常见中文字体。如果图里中文变成方框，说明你电脑缺中文字体，安装其中一个即可。
6. **图 6 配色**：打开 config.py，把 `FIG6_PALETTE` 在 `'warm'`（暖赭，默认）、`'classic'`（原版蓝）、`'forest'`（深青金）之间切换，重跑任务三。
7. **任务六的目标字与规则**：在 config.py 改 `CHAR_TARGETS`（默认酒、雨、花、月）；`CHAR_MIN_CO` 是最低共现诗数（默认 2）；`CHAR_EXCLUDE_CONTAINS` 默认 True，剔除包含目标字自身的二元词（比如查"酒"时不把"酒杯"算邻居，否则构词必然霸榜），想看构词情况改成 False 重跑。
